# 🌲 Aptidão e potencial Silvicultural

Este projeto desenvolve uma análise do **Potencial Silvicultural** utilizando **Google Earth Engine (GEE)** para processamento e visualização de dados espaciais. O objetivo é identificar áreas com aptidão para silvicultura, categorizando-as em diferentes níveis de potencial (Alto, Médio, Baixo, etc.).
